# Kontent.ai Delivery SDK Model Generator

Generates TypeScript models for the [JS Delivery SDK](https://www.npmjs.com/package/@kontent-ai/delivery-sdk). These models include content types, taxonomies, and codename-based types representing elements such as workflow steps, languages, and more.

## Installation

You can install the generator globally, add it as a development dependency, or simply run it using npx for convenience.

```bash
# Install globally (exposes the `kontent-generate-delivery` command)
npm i @kontent-ai/delivery-sdk-model-generator@latest -g

# Install as dev dependency and use in your code
npm i @kontent-ai/delivery-sdk-model-generator@latest --save-dev

# Run with npx
npx @kontent-ai/delivery-sdk-model-generator@latest --help
```

## Compatibility

The generated models target a specific major version of [`@kontent-ai/delivery-sdk`](https://www.npmjs.com/package/@kontent-ai/delivery-sdk). The major version of this generator matches the major version of the Delivery SDK it targets, so use the generator version that matches the Delivery SDK version in your project:

| Model generator                                                 | Delivery SDK (`@kontent-ai/delivery-sdk`) |
| --------------------------------------------------------------- | ----------------------------------------- |
| `@kontent-ai/delivery-sdk-model-generator` `17.x.y`             | `17.x.y`                                  |
| `@kontent-ai/model-generator` `10.x.y` (`delivery-sdk` command) | `16.x.y`                                  |

> [!NOTE]
> The generated models are not cross-compatible across these major versions, e.g. models generated by `17.x.y` will not compile against `@kontent-ai/delivery-sdk@16`.

Upgrading from `@kontent-ai/model-generator@10`? See the [upgrade guide](https://github.com/kontent-ai/model-generator-js/blob/master/upgrade.md).

## Usage

> [!TIP]
> Recommended: Using these models is highly encouraged when working with the JavaScript Delivery SDK, as they provide robust type
> safety and streamline development.

Basic usage

```bash
npx @kontent-ai/delivery-sdk-model-generator@latest
    --environmentId=<id>
    --managementApiKey=<key>
```

Usage with options

```bash
npx @kontent-ai/delivery-sdk-model-generator@latest
    --environmentId=<id>
    --managementApiKey=<key>
    --outputDir=<path>
    --moduleFileExtension=<js | ts | none | mts | mjs>
    --addTimestamp=<true, false>
    --disableComments=<true, false>
    --managementBaseUrl=<proxyUrl>
```

```typescript
import { generateDeliveryModelsAsync } from "@kontent-ai/delivery-sdk-model-generator";

await generateDeliveryModelsAsync({
	// required
	environmentId: "x",
	managementApiKey: "y",
	moduleFileExtension: "js",
	addTimestamp: false,
	createFiles: true,
	outputDir: "/", // only required when createFiles is true

	// optional
	fileResolvers: {
		contentType: (type) => `Custom_${type.codename}`,
		snippet: (snippet) => `Custom_${snippet.codename}`,
		taxonomy: (taxonomy) => `Custom_${taxonomy.codename}`,
	},
	nameResolvers: {
		contentType: (type) => `Custom_${type.codename}`,
		snippet: (snippet) => `Custom_${snippet.codename}`,
		taxonomy: (taxonomy) => `Custom_${taxonomy.codename}`,
	},
	formatOptions: { indentSize: 4, quote: "single" },
	disableComments: false,
	baseUrl: undefined,
});
```

Configuration

| Option                | Description                                                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `environmentId`       | Id of Kontent.ai environment                                                                                                   |
| `managementApiKey`    | Management API key                                                                                                             |
| `moduleFileExtension` | Extension used for imports in generated models.                                                                                |
| `addTimestamp`        | Indicates if models contain timestamp                                                                                          |
| `disableComments`     | If enabled, no comments will be included in the generated files                                                                |
| `createFiles`         | If enabled, files will be created on FileSystem. When disabled you may iterate over the result and process the files yourself. |
| `outputDir`           | Output directory path for files. Only available when `createFiles` is set to `true`                                            |
| `fileResolvers`       | Can be used to customize the generated filenames                                                                               |
| `nameResolvers`       | Can be used to customize names of generated types                                                                              |
| `formatOptions`       | Configuration for formatting generated code                                                                                    |
| `baseUrl`             | Can be used to override default Kontent.ai URLs                                                                                |

## Using the generated models

Pass the generated schema and item union to `createDeliveryClient`. Codenames, element values, filters and responses are then
checked against your environment:

```typescript
import { createDeliveryClient, isContentItemOfType } from "@kontent-ai/delivery-sdk";
import type { MovieItem, TypedClientSchema, TypedItem } from "./models/index.js";

const client = createDeliveryClient<TypedClientSchema, TypedItem>({ apiMode: "public", environmentId: "<id>" });

// `contentTypes` filters by content type and narrows the returned items
const { payload } = await client.listContentItems({ contentTypes: ["movie"] }).fetchPage();
const movies: readonly MovieItem[] = payload.items;

// items of mixed types are narrowed with a guard
const item = (await client.fetchContentItem({ codename: "warrior" }).fetch()).payload.item;
if (isContentItemOfType(item, "movie")) {
	item.elements.title.value;
}
```

Besides the item models, the generator emits codename constants, unions and type guards for content types, elements,
taxonomy terms, multiple choice options, languages, collections and workflow steps.
